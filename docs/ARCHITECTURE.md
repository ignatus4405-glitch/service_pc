# Архитектура PC Care

## Стек

- C# 5, WinForms и .NET Framework 4.5: выбран минимальный runtime, совместимый с Windows 7 SP1 и классическими Windows 8/8.1 при наличии runtime.
- Приложение AnyCPU; Windows Forms — основной интерфейс. Установщик не требуется: релиз — portable ZIP.
- Сборка использует официальные .NET Framework 4.5 reference assemblies NuGet-пакета `Microsoft.NETFramework.ReferenceAssemblies.net45`.

## Слои и поток данных

1. `Program` запускает `MainForm` с manifest `asInvoker` и перечнем поддерживаемых Windows.
2. При показе формы `DiagnosticService.Run()` выполняется в фоне через `Task.Run`. Сервис читает WMI `Win32_OperatingSystem`, `Win32_Processor`, `Win32_DiskDrive`, `Win32_LogicalDisk` и `root\WMI:MSStorageDriver_FailurePredictStatus`.
3. Полученный `SystemSnapshot` локально преобразуется `RecommendationEngine` в детерминированный список `Recommendation`; UI отображает эти же советы на обзорной странице и странице предложений.
4. `CleanupService` независимо от диагностики удаляет старые файлы только из пользовательской папки TEMP; выполнение требует явного подтверждения.
5. `StressTestService` по явному запросу пользователя запускает ограниченные по времени CPU/RAM-проверки: фиксированный проверочный CPU workload на логических ядрах и тест шаблонов в выделенных буферах, с отменой и счётчиками несовпадений. Выделение RAM не превышает четверть текущей свободной памяти, с потолком 1 ГБ (512 МБ для 32-разрядного процесса). Выполнение локальное; тест не стартует при запуске приложения и не собирает/не отправляет системные данные.
6. `WindowsMaintenance` только запускает встроенные средства Windows; он не применяет настройки сам.
7. `UpdateService` получает `/releases/latest` GitHub API, ищет asset `*-windows.zip`. После подтверждения пакет загружается в LocalAppData, распаковывается, запускается `PcCare.Updater.exe`. Помощник ждёт завершения UI-процесса, заменяет EXE и запускает его снова.

## Основа функциональности

Набор сценариев вдохновлён привычной компоновкой уже существующих утилит: CPU-Z/HWiNFO для обзора CPU/RAM, CrystalDiskInfo для понятного SMART health-флага, BleachBit для ограниченной очистки, а также собственными утилитами Windows Optimize Drives/Disk Cleanup. PC Care не является форком этих приложений: их исходники, ресурсы, брендинг и бинарные файлы не включены. Системные значения читаются штатным WMI, обслуживание передаётся штатным компонентам Windows.

## Модель рекомендаций

- SMART `PredictFailure == true` → Critical, рекомендовать резервное копирование и проверку производителем.
- Свободно ≤5% на разделе → Critical; ≤15% → Warning.
- Доступно <10% физической памяти Windows → Warning.
- CPU load ≥85% в момент снимка → Warning с оговоркой, что это кратковременное измерение.
- Нет SMART-строк → Information «состояние не получено»; отсутствие данных никогда не считается здоровьем.
- Если нет Warning/Critical, добавляется нейтральный совет: срочных проблем по доступным данным не найдено, но это не гарантия исправности.

Пороговые правила и тесты расположены в `RecommendationEngine.cs` и `src/PcCare.Tests`.

## Поддержка и ограничения

- На Windows 7 используйте SP1 и .NET Framework 4.5+. Windows 8/8.1/10/11 используют более новую совместимую in-place версию .NET Framework.
- Доступ к `MSStorageDriver_FailurePredictStatus` зависит от конкретного диска/драйвера/RAID/NVMe/USB bridge; SMART не универсален и не заменяет резервные копии или диагностику производителя.
- WMI выдаёт моментальный `LoadPercentage`, а не длительный мониторинг и не температуру CPU.
- Сведения о системе не отправляются. При проверке обновлений на GitHub отправляется только обычный HTTPS GET к API; системный snapshot не включается в запрос.
- GitHub update asset скачивается по HTTPS. Релиз не подписан сертификатом кода; пользователю доступна страница исходного релиза, а обновление требует подтверждения.

## Продолжение разработки

Соблюдайте правила `AGENTS.md`. Изменения источников WMI, правил рекомендаций, очистки или update ZIP требуют синхронного теста/документации/CI. Новые библиотеки должны оставаться совместимыми с .NET Framework 4.5 и Windows 7/8.
