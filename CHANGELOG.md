# История изменений

Формат: основные добавления, изменения поведения и заметные ограничения каждого выпуска.

## Не выпущено — датчики и диагностика накопителей

- Во время ручного теста CPU/RAM добавлен best-effort опрос загрузки CPU, RAM и доступных ACPI thermal zones; ATA SMART-температуры показываются как снимок последней диагностики. Источник и ограничения показаний объясняются в интерфейсе; отсутствие показаний не трактуется как нормальная температура.
- SMART-страница показывает доступный Windows PredictFailure, ATA SMART-атрибуты/пороги и примерную температуру. Названия и raw-значения зависят от производителя, а отсутствие данных не считается признаком исправности.
- Добавлен ручной последовательный read-only скан физического диска с подтверждением, прогрессом, отменой, счётчиками ошибок чтения и медленных блоков. Запись, стирание, ремонт и remap отсутствуют; реальное оборудование не проверяется в CI.
- Документация описывает зависимость SMART от диска, контроллера и драйвера, ограничения ACPI-датчиков и необходимость явного подтверждения для полного чтения.

## Не выпущено — начальная реализация

- Создано настольное приложение PC Care на C# WinForms/.NET Framework 4.5 с русским интерфейсом и совместимостью, рассчитанной на Windows 7 SP1, 8, 8.1, 10 и 11.
- Добавлена локальная диагностика Windows через WMI: ОС, CPU (модель, загрузка-снимок, ядра/потоки/частота), доступная/свободная RAM, физические диски, локальные тома и SMART PredictFailure.
- SMART, который не передан драйвером, обозначается как «нет данных». Приложение не выдаёт такой результат за подтверждение здоровья диска.
- Добавлен движок объяснимых рекомендаций по SMART, статусу физического диска Windows, свободному месту, RAM и высокой моментальной загрузке CPU; рекомендации показываются после завершения проверки.
- Добавлена очистка только старых файлов пользовательского TEMP (возраст более 24 часов), с подтверждением, обходом reparse points, пропуском недоступных/недавних файлов и защитой от ошибочного TEMP, указывающего на корень диска или системную/пользовательскую папку с данными.
- Добавлена отдельная страница нагрузочного тестирования CPU/RAM: тест CPU с проверочными вычислениями на обнаруженных логических ядрах (до 64 потоков), тест шаблонов памяти и комбинированный режим; 1/5/15 минут, прогресс, счётчики ошибок и отмена. Тест не стартует автоматически, требует подтверждения, ограничивает выделение RAM четвертью доступной памяти и максимумом 1 ГБ (512 МБ для 32-разрядного процесса); GPU/VRAM и блок питания не проверяются, доступные температурные датчики best-effort.
- Добавлены ручные переходы к штатным средствам Windows: оптимизации дисков, очистке диска, управлению автозагрузкой и Диспетчеру задач. Автоматические изменения реестра/служб не выполняются.
- Добавлены GitHub Actions для CI-сборки/тестов, формирования ZIP-релиза по semver-тегу, установка версии сборки из тега, проверка новых релизов и пользовательски подтверждаемое обновление; Actions обновлены до Node 24-совместимых версий.
- Добавлены четырнадцать тестов рекомендаций, безопасной очистки, проверочных правил нагрузочного теста, парсинга SMART и классификации задержек чтения, общий PowerShell-скрипт сборки с диагностическими GitHub annotations, инструкция разработчика, архитектурные ограничения и правила продолжения работы для агентов.
