# PC Care — диагностика и обслуживание Windows

PC Care — настольная утилита на русском языке для первичной диагностики ПК. Поддерживаются **Windows 7 SP1, Windows 8, 8.1, 10 и 11**. Интерфейс показывает состояние процессора, оперативной памяти, разделов и доступный Windows SMART-статус, формирует предложения после проверки, выполняет ограниченную очистку временных файлов и открывает штатные средства обслуживания Windows.

## Возможности

- **Автоматическая первичная проверка при запуске** и повторный запуск вручную: имя/загрузка CPU, ядра и потоки, доступная/свободная память, свободное место на локальных дисках, список физических дисков.
- **SMART через WMI** (`MSStorageDriver_FailurePredictStatus`). Если драйвер накопителя не предоставляет SMART, приложение честно показывает «нет данных» — это не считается доказательством исправности или неисправности.
- **Предложения по оптимизации** после диагностики: критическое SMART-предупреждение, нехватка места или памяти, высокая загрузка процессора во время снимка и безопасные следующие шаги.
- **Очистка временных файлов** только из TEMP текущего пользователя. По подтверждению пользователя удаляются файлы старше 24 часов; занятые, недавние и недоступные файлы пропускаются. Браузерные пароли/cookies, документы, корзина, Prefetch и системные папки не затрагиваются.
- **Оптимизация системы** через встроенные окна Windows: «Оптимизация дисков», «Очистка диска», автозагрузка и Диспетчер задач. PC Care не отключает службы, не меняет реестр, не разгоняет компоненты и не запускает скрытые фоновые операции.
- **Проверка GitHub Releases** при старте. При обнаружении более новой версии показывается уведомление; скачивание и установка требуют подтверждения. Для каталога `Program Files` может появиться запрос UAC.
- **Сборка и тесты в GitHub Actions** при push/PR; публикация ZIP — по тегу версии.

## Запуск

Скачайте `PcCare-vX.Y.Z-windows.zip` из раздела [GitHub Releases](https://github.com/ignatus4405-glitch/service_pc/releases), распакуйте в пользовательскую папку и запустите `PcCare.exe`.

Требуется **.NET Framework 4.5 или новее**. На Windows 7 SP1 его при необходимости нужно установить отдельно; Windows 8 включает .NET 4.5, более новые системы содержат совместимые версии .NET Framework. Приложение не требует прав администратора для диагностики и очистки своего TEMP-каталога. Проверка SMART и отдельные поля зависят от WMI-драйверов производителя.

## Сборка и тесты

Сборка рассчитана на Windows и MSBuild (Visual Studio Build Tools). GitHub Actions автоматически скачивает reference assemblies .NET Framework 4.5, собирает `PcCare.sln` и запускает тесты рекомендаций. Локально из корня репозитория:

```powershell
nuget install .\build\packages.config -OutputDirectory packages -NonInteractive
./scripts/build.ps1 -Configuration Release
.\src\PcCare.Tests\bin\Release\PcCare.Tests.exe
```

Основной результат — `src/PcCare/bin/Release/PcCare.exe`; помощник перезапуска обновления — `src/PcCare.Updater/bin/Release/PcCare.Updater.exe`.

## Публикация новой версии

1. Обновите `CHANGELOG.md` и проверьте сборку/тесты.
2. Создайте и отправьте на GitHub тег стабильной версии вида `vMAJOR.MINOR.PATCH`, например `v1.1.0`.
3. Workflow **Publish Windows release** проставит версию из тега, соберёт приложение и тесты, создаст `PcCare-v1.1.0-windows.zip` и опубликует GitHub Release.
4. Клиенты при следующем запуске проверят `releases/latest` этого репозитория и получат уведомление.
